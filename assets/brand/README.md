# Brand icons

Used only to link to this project's own GitHub organisation, YouTube channel, and Ko-fi page, as the brands' guidelines allow.

- `github-mark*.svg` – GitHub's `mark-github` from [@primer/octicons](https://github.com/primer/octicons) 19.42.0 (MIT). Guidelines: https://github.com/logos
- `youtube-icon.svg` – YouTube icon from [simple-icons](https://simpleicons.org) 16.35.0 (CC0), in YouTube's official red #FF0000 with a white play triangle. Guidelines: https://www.youtube.com/howyoutubeworks/resources/brand-resources/
- `kofi-icon.svg` – Ko-fi icon from [simple-icons](https://simpleicons.org) 16.35.0 (CC0), in Ko-fi's colour #FF6433. Brand assets: https://more.ko-fi.com/brand-assets
